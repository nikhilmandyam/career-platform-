## 3. What went wrong

Azure for Students blocked resource deployment with `RequestDisallowedByAzure`. The error said my subscription is restricted to a set of best available regions. West US 2 failed, so I used Azure CLI to investigate where `Standard_B2ts_v2` was available. I also tried West Central US and Chile Central, and both failed with the same policy error. This confirmed the blocker was Azure regional policy rather than the app code or SSH setup. Since no VM existed, I could not perform the later migration checks.

## 4. The change

At a coffee shop, SSH would likely hang because the firewall rule allows only the public IP address of the network I was using before. I would find the coffee shop's current public IPv4 address and update the Allow-SSH-Laptop rule to that address with `/32` instead of opening SSH to everyone. Updating the firewall rule does not add a separate service charge; normal Azure resource costs still apply.
